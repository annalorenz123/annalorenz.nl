# Hop hop! website

A small static website that animates the supplied photo with a gentle up-and-down hop.

## Files
- `index.html` — page structure
- `style.css` — layout and animation
- `script.js` — pause/resume and speed controls
- `images/photo.jpg` — supplied photo, optimized for the web

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
